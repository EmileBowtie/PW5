# UMP — Ultimate Math Practice

A simple VS Code project containing the UMP demo website.

## Open the project
1. Extract the ZIP archive.
2. Open the `UMP-VSCode` folder in Visual Studio Code (`File → Open Folder`).
3. Open `index.html`.

## Preview on your PC

Recommended: install the **Live Server** extension in VS Code, then right-click `index.html` and choose **Open with Live Server**.

The site will usually open at `http://127.0.0.1:5500`.

## Open it on your phone (same Wi-Fi)

1. Connect your phone and PC to the same Wi-Fi network.
2. Find your PC's local IPv4 address: open Command Prompt and run `ipconfig`; look for the IPv4 Address under your active Wi-Fi/Ethernet adapter.
3. In Live Server settings, set `liveServer.settings.host` to `0.0.0.0` if needed, then restart Live Server.
4. On your phone, open `http://YOUR-PC-IP:5500` (replace `YOUR-PC-IP` with the IPv4 address).
5. If Windows Firewall asks, allow access on your private network.

Your PC and Live Server must remain running while you use the site. This local address will not work from outside your home/network. To share a public link over WhatsApp that works anywhere, you will need a hosting service or a secure tunnel.
